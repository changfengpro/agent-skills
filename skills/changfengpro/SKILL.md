# 长风Pro 项目编码规范

这是用户为「长风Pro」项目立下的**硬性编码约定**。写代码、脚本、配置、改路径时按此执行；用户会不断往里加新条目，每条都带「要求 / 为什么 / 怎么做」。

> 维护方式：新增条目往下追加，编号递增；不要删旧条目（除非用户明确作废）。每条尽量给正反例。

## 规范 1：避免硬编码，优先相对路径

**要求：** 能用相对路径就不用绝对路径；**绝不把"会变的东西"写死在代码里**——包括但不限于：绝对路径、IP 地址、端口、`/dev/videoN` 设备号、用户名、主机名、密码、模型/文件路径。能从脚本自身位置派生、能参数化、能配置化、能自动发现的，就别写死。

**为什么：** 写死的路径一旦项目目录搬动（例如从 `~/下载/` 移到 `~/project/python/`）就全线崩溃——本项目已经因此踩过坑：脚本里写死 `/home/rmer/下载/siglip_rknn`，目录一搬，glob 到空、产物落错地方、转换找不到校准集。写死的 IP/端口/设备号在换板子、换网段、换摄像头节点时同样全废。

**怎么做：**
- **路径根**用脚本自身目录派生，而不是写死绝对路径：
  ```python
  # ✅ 推荐
  import os
  ROOT = os.path.dirname(os.path.abspath(__file__))
  data = os.path.join(ROOT, 'crops_calib')

  # ❌ 禁止
  ROOT = '/home/rmer/下载/siglip_rknn'
  ```
- **可变量**（IP/端口/设备号/模型路径等）走**命令行参数、环境变量或配置文件**，给合理默认值，别焊死在源码里：
  ```python
  # ✅
  import sys, os
  RKNN = sys.argv[1] if len(sys.argv) > 1 else os.path.join(ROOT, 'model.rknn')
  BOARD_IP = os.environ.get('BOARD_IP', '10.31.3.11')

  # ❌
  RKNN = '/userdata/siglip/model.rknn'; BOARD_IP = '10.31.3.11'
  ```
- 列表/清单文件（如 RKNN 校准集 `calib_list.txt`）里**也别存绝对路径**，用相对路径或运行时生成。
- 板端部署路径（`/userdata/...`）这类约定俗成的固定值可保留，但仍优先做成脚本顶部常量或参数，集中一处便于改。
- 实在需要绝对路径时，集中到一个配置/常量区，不要散落各处。
